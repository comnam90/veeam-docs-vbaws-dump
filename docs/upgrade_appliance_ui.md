# Updating Backup Appliances


Veeam Backup for AWS automatically notifies you about newly released product versions and software package updates available for the operating system running on the backup appliance. However, starting from Veeam Backup for AWS version 6a, you can use the Veeam Backup for AWS Web UI to install software package updates only.
